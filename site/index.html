Paddr

Paddr is a menu-bar app that maps the trackpads, rear buttons, grips and gyro of a Steam Controller 2 to mouse, scroll and keyboard input on an Apple silicon Mac running macOS 27 or later, with the controller connected through its puck.

Mappings

What each control can send
Control Sends
Trackpad, Pointer mode Mouse pointer movement.
Trackpad, Scroll mode Scrolling, vertical and horizontal.
Trackpad, Zones mode A key or mouse button for each zone, held while the zone is touched. A pad has 2, 4 or 9 zones.
  • Four-way radial
  • Four corners
  • Left / right
  • Top / bottom
  • 3 × 3 grid
Tap on a trackpad A key, left click or right click. Pointer and Scroll modes only.
Rear buttons L4, L5, R4, R5 A key or mouse button, held while the button is held.
Left grip, right grip A key or mouse button, held while the grip is touched.
Gyro Mouse movement while a chosen grip or pad is touched, or always. Off by default. Calibrate it after turning output on; calibration is not saved.
Other buttons, sticks, triggers Not mapped by Paddr. macOS handles them through its own controller support.

The left and right trackpads are set separately. A set of mappings is saved as a profile, and you switch profiles from the window toolbar or the menu-bar menu.

Requirements

What you need to run Paddr
Item Requirement
Mac Apple silicon, running macOS 27 or later.
Controller Steam Controller 2, connected through its puck.
macOS permissions Input Monitoring, to read the controller. Accessibility, to send mouse and keyboard input.
Steam Not required. That includes Steam Input and Steam Overlay.

Install

  1. Download Get Paddr.zip from GitHub Releases, unzip it, and move Paddr.app to Applications.
  2. Grant permissions Open Paddr. Its window shows a setup checklist. Grant Input Monitoring and Accessibility from there.
  3. Edit a profile The built-in Default profile makes the left pad scroll and the right pad move the pointer, and cannot be edited. To change mappings, choose Duplicate to Edit, make your changes, then choose Save & Apply. Saving does not turn output on.
  4. Turn on output Turn on Enable output, then release the pads and any assigned rear buttons and grips. Output starts once they are released. Closing the window leaves Paddr running in the menu bar.

Not supported or not confirmed

What is not supported or not confirmed
Item Status
Bluetooth, direct USB Not validated. Only the puck connection is confirmed.
macOS versions Confirmed by the maintainer on released macOS 27 and the macOS 27.2 release candidate.
Games Works with games launched directly, such as World of Warcraft. Support varies by game: games that capture the mouse for aiming, or that read raw controller input, may ignore Paddr’s events.
Virtual gamepad Not supported. Paddr sends mouse, scroll and keyboard events only, not stick or trigger input.
Grip pressure Not supported. The grips report touch, not how hard they are squeezed.
Gyro without motion data Gyro uses the motion data the puck already sends. If none arrives, gyro is unavailable for that session.
Controller firmware Not modified. Paddr only reads the reports the puck sends.
